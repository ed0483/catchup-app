**Options:** React + Node/Express, React + PHP, React + Python/FastAPI

**Chose:** Python with FastAPI

**Why:** The best tools for reading PDFs and working with AI are made for
Python first; Node versions often come later or have fewer features. I also
plan to add grade prediction with machine learning, and nearly all ML tools

start while I learn a new language and framework.
